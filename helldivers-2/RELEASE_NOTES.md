### What's in it

The first release of the Helldivers 2 add-on: every stratagem on its own key.

- **One press per stratagem.** Open the stratagem menu (TAB), then a key taps
  the code on W A S D, the game's default directions. It needs galleon-deck 1.2.0 for the new
  `sequence` action.
- **Six pages:** mission, orbital, eagle, weapons, support and defense, 67 stratagems in all.
- **Colour-coded like the game:** red offensive, blue supply, green defensive, yellow
  mission, on the `hd-super-earth` theme.
- **Auto-switch:** the profile carries its own rule for the Steam build under Proton.
